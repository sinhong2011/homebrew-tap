# sinhong2011/tap

Homebrew casks for [Triwarden](https://github.com/sinhong2011/triwarden), a native Mac password manager for
Vaultwarden and Bitwarden.

```bash
brew install sinhong2011/tap/triwarden
```

The cask also links the `tw` command-line tool onto your PATH. Casks here are updated automatically by each
Triwarden release.
